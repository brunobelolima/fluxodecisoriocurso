# Curso de Cuidados Paliativos por Telessaúde

Fluxo decisório interativo de apoio ao planejamento educacional. HTML, CSS e JavaScript sem dependências externas.

## Uso local
Abra `index.html` no navegador. Escolha o perfil do curso e clique em **Construir curso**. O resultado inclui módulos A–D, pedagogia, telessaúde, formato e avaliação. Use **Imprimir / salvar em PDF** para exportar.

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório (o `index.html` deve ficar na raiz).
3. Em Settings → Pages, selecione publicação pela branch `main`, pasta `/ (root)`, e salve.
4. Aguarde a publicação e abra o endereço exibido pelo GitHub.

## Arquivos
- `index.html`: formulário e estrutura da página.
- `styles.css`: identidade visual, responsividade e impressão.
- `app.js`: regras de decisão, validação, resultados e reinício.
- `.nojekyll`: permite servir os arquivos estáticos diretamente.

## Escopo
As regras são propostas de planejamento, não um instrumento validado. Habilidades, autoeficácia e transferência são medidas distintas. A carga horária precisa ser estimada a partir das atividades e competências. A ferramenta não coleta ou transmite dados e não deve receber dados identificáveis de pacientes. As competências profissionais precisam ser detalhadas conforme a regulamentação aplicável antes de compor o currículo final.
